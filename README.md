# فضفضة 💜
موقع عربي متجاوب للجوال لمبادرة التوجيه الطلابي. يضم دردشة «رفيقة»، إملاء صوتيًا حسب دعم المتصفح، قراءة صوتية لردود الروبوت، ولوحة منسقة التوجيه المحمية بكلمة مرور.

## تجربة الموقع على الكمبيوتر
1. ثبتي Node.js إصدار 20 أو أحدث.
2. افتحي مجلد الموقع في الطرفية.
3. ضعي متغيرات البيئة `ADMIN_PASSWORD` (ضروري للوحة الإدارة)، و`SESSION_SECRET` (ضروري للحفاظ على الجلسات عند إعادة التشغيل)، واختياريًا `OPENAI_API_KEY`.
4. شغلي `npm start`، ثم افتحي `http://localhost:3000` و`http://localhost:3000/admin.html`.

**مهم:** هذا ملف مشروع وليس موقعًا منشورًا على الإنترنت. نشره برابط عام يتطلب استضافة تدعم Node.js (مثل Render أو Railway). أضيفي متغيرات البيئة من إعدادات المنصة، ولا تكتبي مفتاح API في `public` أو ترفعيه ضمن ملفات الموقع. استخدمي HTTPS.

## ماذا يعمل؟
- بدون `OPENAI_API_KEY`: يعمل وضع تجريبي بردود محدودة جاهزة، **ليس ذكاءً اصطناعيًا كاملًا**.
- مع `OPENAI_API_KEY`: يحصل الموقع على ردود ذكاء اصطناعي من الخادم، ولا يُرسل المفتاح إلى المتصفح. قد تطبق رسوم استخدام API.
- الرسائل تحفظ في `data/messages.json` على خادم الموقع. بيانات الاستضافة قد تكون مؤقتة، وبهذا يلزم تخزين دائم في الإنتاج.
- الرسائل مجهولة الاسم لكن قد تكتب الطالبة معلومات تعريفية في النص؛ ينبغي وضع سياسة موافقة وحماية بيانات ومدة احتفاظ محددة والتنسيق مع إدارة المدرسة قبل فتح الموقع للطالبات.
- لوحة الإدارة نموذج أولي، يحتاج قبل الإطلاق الحقيقي: ضبط صلاحيات أكثر، تحديد الاحتفاظ والحذف، معدل طلبات، مراجعة أمنية، مسار إحالة للحالات الحساسة، واستضافة متوافقة مع متطلبات حماية بيانات الطالبات.
- النصوص الخاصة بالمخاطر هي توجيه أولي ولا تغني عن تدخل بشري فوري.
- الإملاء الصوتي يختلف دعمه باختلاف الهاتف والمتصفح؛ خيار مايك لوحة مفاتيح الجوال بديل.
